## B-roll

Whenever a line names a person, company, product, place or event, get b-roll for it with find_broll
(or plan_broll for the whole script). Send the line as context and 1-3 short keywords.

- Use the top shot. Download images from download_url. For videos, run the shot's cut_command, which cuts
  only the seconds you need on this machine.
- Save every file in the project's media folder: public/broll/ for Remotion, assets/broll/ for HyperFrames.
- Start each shot on the word it illustrates, and hold it 2-4 seconds.
- Put each shot's credit line (license.attribution) in the credits or the description.
- A shot marked "Not cleared" (license.cleared false) needs the owner's permission before commercial use.
